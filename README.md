# Personal Profile Page

This is a static GitHub Pages-ready profile page for Junhyuk Choi.

## Customize Before Publishing

- Replace `your.email@example.com` in `index.html` with your real contact email.
- Replace the LinkedIn URL with your real profile.
- Add a CV PDF under `assets/` and change `CV coming soon` to a normal link.
- Replace the three selected work placeholders with real research, engineering, or open-source projects.
- Adjust the research interest cards once your lab direction is more specific.

## Local Preview

Open `index.html` directly in a browser. No build step is required.
